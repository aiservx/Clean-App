# المرحلة الأولى: فحص المشروع بالكامل

قبل تعديل أي شيء قم بـ:

1. فحص هيكل المشروع كاملًا

2. تحديد:

   * frontend architecture
   * backend architecture
   * database structure
   * APIs
   * chatbot architecture
   * notification system
   * booking flow
   * invoice system
   * ticket system
   * refund system

3. إنشاء ملف:

```bash
PROJECT_MEMORY.md
```

يحتوي على:

* هيكل المشروع
* أسماء الملفات المهمة
* العلاقات بين الأنظمة
* APIs
* database schema
* كل تعديل يتم لاحقًا

هذا الملف يجب تحديثه بعد كل تعديل جديد حتى لا يتم استهلاك التوكنز مستقبلًا في إعادة فهم المشروع.

# المرحلة الثانية: تعديل بطاقة نجاح الحجز

في شاشة نجاح الحجز الحالية يوجد:

* زر حجز خدمة جديدة

أريد إضافة زر جديد بجواره:

### "تتبع الطلب"

الشروط:

* يكون أكبر حجمًا من زر "حجز خدمة جديدة"
* أكثر بروزًا
* primary CTA
* تصميم حديث جدًا
* animation hover
* loading state
* modern gradients
* responsive

مثال:

```text
[ تتبع الطلب ]   [ حجز خدمة جديدة ]
```

زر تتبع الطلب عند الضغط:

ينقل المستخدم مباشرة إلى:

* صفحة التتبع
  أو
* modal tracking
  أو
* chat tracking card

حسب architecture الأفضل.
