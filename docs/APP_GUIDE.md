# دليل تطبيق نظافة — الدليل الشامل

> **نظافة** — منصة خدمات التنظيف المنزلية والتجارية بالسعودية  
> متوفر على Android · الإصدار 1.0.0 (Build 20)

---

## نبذة عن التطبيق

نظافة هو تطبيق جوال متكامل يربط العملاء بمزودي خدمات التنظيف المعتمدين في المملكة العربية السعودية. يتيح التطبيق حجز الخدمات فوراً أو بموعد مسبق، تتبع المزود على الخريطة في الوقت الفعلي، والتواصل المباشر عبر المحادثة الفورية.

---

## الميزات الرئيسية

### للعملاء

#### الحجز الذكي
- اختيار من **18 فئة خدمة** (تنظيف منازل، شقق، فلل، مكاتب، مسابح، سيارات، وأكثر)
- حجز **فوري** (يصل المزود خلال دقائق) أو **بموعد مسبق** (تاريخ ووقت محدد)
- تفاصيل الخدمة: وصف كامل، مدة التنفيذ، السعر الأساسي
- إضافة ملاحظات خاصة للمزود

#### تتبع الطلب الحي
- خريطة تفاعلية تعرض موقع المزود لحظة بلحظة
- شريط تقدم بـ 6 مراحل: **انتظار ← تأكيد ← في الطريق ← وصل ← بدأ العمل ← اكتمل**
- إشعارات آنية عند كل تغيير في الحالة
- سجل تفصيلي بتواريخ وأوقات كل مرحلة

#### المساعد الذكي
- دردشة ذكية تفاعلية لحجز الخدمات خطوة بخطوة
- إدخال صوتي بالعربية مع تحويل آلي للنص
- قراءة صوتية للردود (Text-to-Speech بالعربية)
- استعراض الفاتورة وتتبع الطلبات من داخل المحادثة

#### إدارة الطلبات
- عرض جميع الطلبات النشطة والمنتهية
- فاتورة مفصلة (سعر الخدمة + رسوم + ضريبة القيمة المضافة)
- طلب استرداد المبلغ مع إرفاق الأسباب
- تقييم المزود بعد إتمام الخدمة (5 نجوم)

#### العروض والمكافآت
- تصفح العروض الخاصة والتخفيضات الموسمية
- نظام إحالة الأصدقاء مع مكافآت مالية
- عضوية بريميوم بامتيازات حصرية

### لمزودي الخدمة

#### لوحة تحكم المزود
- عرض الطلبات الجديدة فور ورودها مع عداد تنازلي للقبول
- قبول أو رفض الطلبات مباشرة من الإشعار
- إدارة الطلبات النشطة والمجدولة والمنتهية

#### الأرباح والمحفظة
- متابعة الأرباح اليومية والشهرية مع رسوم بيانية
- طلب سحب الأرباح مباشرة
- كشف حساب مفصل قابل للمشاركة

#### الملف المهني
- رفع الصور الشخصية وشهادات الكفاءة
- تحديد منطقة الخدمة ونطاق التغطية الجغرافية
- ضبط ساعات العمل وأيام الدوام
- تحديث الموقع تلقائياً أثناء التنقل

## كيفية الاستخدام

### الخطوة الأولى: إنشاء حساب
1. افتح التطبيق وانقر **"إنشاء حساب جديد"**
2. أدخل الاسم الكامل ورقم الجوال والبريد الإلكتروني
3. اختر نوع الحساب: **عميل** أو **مزود خدمة**
4. تحقق من هاتفك واكتمل التسجيل

### الخطوة الثانية: حجز خدمة (للعملاء)
1. من الصفحة الرئيسية، اختر فئة الخدمة المطلوبة
2. حدد نوع الحجز: **الآن** أو **موعد لاحق**
3. أضف أو اختر العنوان من قائمة عناوينك المحفوظة
4. راجع الفاتورة وأكد الحجز
5. انتظر قبول المزود وتتبعه على الخريطة

### الخطوة الثالثة: التتبع والتواصل
- انقر على الطلب من صفحة **"طلباتي"** للتتبع المباشر
- استخدم زر **المحادثة** للتواصل مع المزود
- ستصلك إشعارات تلقائية عند كل تحديث

## الشاشات والمقاطع

| الشاشة | الوصف |
|--------|-------|
| **الرئيسية** | خريطة تفاعلية + فئات الخدمات + عروض + مزودون قريبون |
| **المساعد الذكي** | محادثة ذكية بالعربية مع دعم صوتي |
| **تتبع الطلب** | خريطة حية + شريط التقدم + معلومات المزود |
| **طلباتي** | قائمة كاملة بالطلبات النشطة والمنتهية |
| **المحادثات** | شات مباشر مع المزود لكل طلب |
| **العروض** | قسائم وتخفيضات مخصصة |
| **حسابي** | إدارة الملف الشخصي والعناوين والإعدادات |
